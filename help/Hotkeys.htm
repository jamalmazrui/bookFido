bookFido Hotkeys

The keys of bookFido’s opening dialog, which gathers a catalog of your books from five libraries. The keys are given three ways: by command name, by key, and in the order Tab reaches the controls. Each Alt key is the letter underlined in its control’s label, so a screen reader says it with the control. OK and Cancel have no letter: Control+Enter is OK and Escape is Cancel, from any control. Shift+F1, Control+Slash, F7 and F11 work in every Homer dialog, the messages bookFido shows included.

By Command Name

Commands in alphabetical order.

  • Audible, Alt+A – Gather the Audible library, its companion PDF files, and its catalog.
  • Bookshare, Alt+B – Gather the Bookshare My History list.
  • Cancel, Escape – Close the dialog without starting, from any control.
  • Elevate Version, F11 – Download and install the latest bookFido.
  • Goodreads, Alt+G – Gather the Goodreads My Books shelves.
  • Help, F1 – List each control with its tip, and the dialog keys.
  • Kindle, Alt+K – Gather the Kindle library on the Amazon account.
  • List Controls, F7 – List the dialog’s controls, and move to the one chosen.
  • NLS, Alt+N – Gather the National Library Service reading history, from BARD.
  • OK, Control+Enter or Enter – Start the search: Control+Enter from any control, Enter from any but a button.
  • Open bookFido, Alt+Control+Shift+B – Open the bookFido dialog from anywhere in Windows, with its desktop shortcut.
  • What This Does, Shift+F1 – Say what the control with focus does.
  • Where Am I, Control+Slash – Say where you are, what has focus and its keys.

By Key

Keys in order of how many are pressed together, then alphabetically.

  • Enter – OK: Start the search: Control+Enter from any control, Enter from any but a button.
  • Escape – Cancel: Close the dialog without starting, from any control.
  • F1 – Help: List each control with its tip, and the dialog keys.
  • F7 – List Controls: List the dialog’s controls, and move to the one chosen.
  • F11 – Elevate Version: Download and install the latest bookFido.
  • Alt+A – Audible: Gather the Audible library, its companion PDF files, and its catalog.
  • Alt+B – Bookshare: Gather the Bookshare My History list.
  • Alt+G – Goodreads: Gather the Goodreads My Books shelves.
  • Alt+K – Kindle: Gather the Kindle library on the Amazon account.
  • Alt+N – NLS: Gather the National Library Service reading history, from BARD.
  • Control+Enter – OK: Start the search: Control+Enter from any control, Enter from any but a button.
  • Control+Slash – Where Am I: Say where you are, what has focus and its keys.
  • Shift+F1 – What This Does: Say what the control with focus does.
  • Alt+Control+Shift+B – Open bookFido: Open the bookFido dialog from anywhere in Windows, with its desktop shortcut.

In Tab Order

The dialog reads top to bottom, in this order:

  1. The introduction, a read-only text box saying what bookFido does
  2. Audible – Alt+A
  3. Bookshare – Alt+B
  4. Goodreads – Alt+G
  5. Kindle – Alt+K
  6. NLS – Alt+N
  7. OK and Cancel, alone at the bottom right: Control+Enter is OK and Escape is Cancel, from any control

Text Box Keys

Every text box in the dialog is a Homer text box, with these keys too. A dialog’s own letter comes first: where a control’s underlined letter is the same as one of these, as Alt+C is Choose output directory, Alt and that letter goes to the control.

  • Control+A – Select All: Select all the text in the box.
  • Control+Shift+A – Unselect All: Clear the selection, keeping the cursor where it is.
  • Control+C – Copy: Copy the selection, or the current line when nothing is selected.
  • Control+X – Cut: Cut the selection, or the current line when nothing is selected.
  • Alt+X – Cut Append: Cut the selection or line and add it to what the clipboard holds, unless a control in the dialog has X as its letter.
  • Alt+C – Copy Append: Copy the selection or line and add it to what the clipboard holds, unless a control in the dialog has C as its letter.
  • Control+D – Delete Line: Delete the current line, without the clipboard.
  • F8 – Start Selection: Mark where a selection starts.
  • Shift+F8 – Complete Selection: Select from the start mark to the cursor.
  • Control+F8 – Copy All: Copy all the text in the box.
  • Alt+F8 – Read All: Read all the text in the box aloud.
  • Alt+Y – Say Yield: Say how many lines and characters the box holds, unless a control in the dialog has Y as its letter.
  • Alt+Apostrophe – Say Clipboard: Say what the clipboard holds.

Why These Keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because “elevate” sounds like “eleven”. Each library’s letter is the first letter of its name. Alt+Control+Shift+B belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts, and B is the first letter of bookFido. Shift is there because plain Alt+Control+B is already BatCon’s, another Homer app, and is claimed by Figma, JetBrains programs and Oracle web applications too.

# bookFido Hotkeys

The keys of bookFido's opening dialog, listed three ways. Each Alt key is the letter underlined in its checkbox, the first letter of the library's name, so a screen reader reads it with the checkbox. OK and Cancel have no letter: Enter is OK and Escape is Cancel.

## By key

- Alt+A — Audible
- Alt+B — Bookshare
- Alt+Control+Shift+B — open bookFido from anywhere (the desktop shortcut)
- Alt+G — Goodreads
- Alt+K — Kindle
- Alt+N — NLS
- Control+Enter — OK, from any control
- Enter — OK: start the run
- Escape — Cancel: close without searching
- F1 — Help
- F11 — check for a newer version
- Shift+F1 — say the focus tip for the current control

## By command

- Audible — Alt+A
- Bookshare — Alt+B
- Cancel — Escape
- Check for a newer version — F11
- Goodreads — Alt+G
- Help — F1
- Kindle — Alt+K
- NLS — Alt+N
- OK — Enter, or Control+Enter from any control
- Open bookFido from anywhere — Alt+Control+Shift+B
- Say the focus tip — Shift+F1

## In tab order

1. The introduction, a read-only text field
2. Audible — Alt+A
3. Bookshare — Alt+B
4. Goodreads — Alt+G
5. Kindle — Alt+K
6. NLS — Alt+N
7. The buttons: OK (Enter) and Cancel (Escape)

## Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because "elevate" sounds like "eleven". Alt+Control+Shift+B belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts, and B is the first letter of bookFido. Shift is there because plain Alt+Control+B is already claimed by Figma, JetBrains programs and Oracle web applications, and a desktop hotkey works everywhere in Windows.
